How to Use

  1. Select a cheque leaf number from your allocated cheque leaves
  2. Set the date to be printed on the cheque
  3. Enter the withdrawal amount (max ₹50,00,000 per cheque)
  4. Enter the payee name exactly as it should appear on cheque
  5. Click Submit Request to send for admin approval
  6. Once approved, you can download the printable savings cheque
  7. Cancelled cheques return the leaf back to available pool
